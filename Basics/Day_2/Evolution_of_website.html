1.Why did people need websites? Before websites, information was mainly shared through books, newspapers, letters, telephone calls, and physical documents. "What if we could store information on computers and allow other people to access it?" This created the need for a system to share information between computers. 2.What was the first major idea? Scientists and researchers were working with many documents and computers. They needed an easy way to: Store information Find information Connect one document to another Share information with other researchers So the idea of hypertext became important. 3.What is Hypertext? Hypertext means text that can connect to another piece of information. For example: "Click here to learn about Computers." When you click it, you go to another document. That clickable connection is the basic idea behind the link we use on websites today. 4.Who created the World Wide Web? In 1989, Tim Berners-Lee proposed the World Wide Web while working at CERN. His basic idea was: "Let's create a system where documents can be connected using links and accessed through a network." 5.What did he need to make the Web work? He developed three important technologies: HTML → HTTP → URL Think of them like this: HTML → How the document is structured HTTP → How the document is transferred URL → Where the document is located Together, they formed the foundation of the Web. 6.What was the first website like? The first websites were extremely simple compared with today's websites. They mainly contained: Text Headings Links Basic information There were no: Instagram-style feeds Online shopping YouTube videos Animations Modern buttons Complex designs It was basically information + links. 7.Why did websites initially look so simple? Because the original purpose of the Web was mainly sharing information, not creating beautiful designs. Also, computers and internet connections were much less powerful. So the priority was: "Make information available." Not: "Make it beautiful." 8.Then why did websites become more beautiful? People started asking: "Can we change the appearance of the webpage?" This led to the development and widespread use of CSS (Cascading Style Sheets). HTML was mainly responsible for structure. CSS became responsible for appearance. For example: HTML: "Here is a heading." CSS: "Make the heading blue, large, centered, etc." 9.Was HTML + CSS enough? Not for everything. People then asked: "Can a website actually DO something?" For example: Click a button Calculate something Show/hide information Validate a form Respond to the user This created the need for JavaScript. 10.What did JavaScript change? JavaScript made webpages interactive. The evolution became: HTML → Structure ↓ CSS → Design ↓ JavaScript → Interaction Now a webpage wasn't just something you read. You could interact with it. 11.What happened when more people started using websites? Websites became more complicated. Businesses started thinking: "We need websites for our companies." Then came: Company websites News websites Search engines Online stores Educational websites Banking websites The Web became much more important. 12.What is the difference between the early Web and this new Web? Early We You mostly: Read information This is often called Web 1.0. Example : A webpage gives you information about a company. You read it, but you don't do much with it. Later Web You could: Read + Write + Interact This is commonly called Web 2.0. Examples: Facebook YouTube Wikipedia Blogs Online shopping Social media Users were no longer just readers. They became content creators too. 13.What problem came with complex websites? Developers had to write a huge amount of code. Imagine creating 100 buttons, forms, menus, cards, etc. Developers thought: "Can we reuse things instead of building everything from zero?" This led to tools and frameworks such as: Bootstrap jQuery React Angular Vue Tailwind CSS These made modern website development easier and faster. 14.Why did mobile phones change websites? People started accessing websites from: Computers Laptops Tablets Smartphones A website designed only for a large computer screen could look terrible on a phone. So developers needed websites that could adapt to different screen sizes. This idea is called: Responsive Web Design 15.What happened after websites became interactive? Websites started behaving more like applications. For example, instead of simply visiting a page: "Amazon gives product information." You could: Search → Select product → Add to cart → Pay → Track order The website was now doing complex work. This led to the idea of Web Applications. 16.Where does the database come into the picture? When websites started handling large amounts of information, they needed somewhere to store it. For example: A shopping website needs to store: User accounts Products Prices Orders Payments Addresses This is where databases and SQL became important. So a modern website can involve: Frontend → Backend → Database 17.What is a modern website today? Today's website can be much more than a document.
