What is HTML

HTML Stands for HyperText Markup language. It is used to structure a unstructured document

Definnition of HTML

  • HYPER- It means connecting one page to another page is called Hyper.
  • TEXT- Means the content we have
  • MARKUP- means the tags and syntax used to structure the unstructured Content
  • LANGUAGE-means The rules and syntax used to communicate with browser.

What is webpage and website

Single Structure document with collection of tags, elements and content area called Web page.

Website is a collection of webpages. A website can have n number of webpages

There are two types of website Static(only developer can change),Dynamic (user can intract or change)
